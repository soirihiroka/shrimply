Windows
=======

Windows is currently community-supported.

Requirements
------------

* **OS**: Windows 10 or later (x86_64).
* **GPU**: a compatible NVIDIA GPU (Turing through Blackwell; GTX 900+ may
  work) with up-to-date NVIDIA drivers.

Installation
------------

Download a prerelease build from the `GitHub releases page
<https://github.com/soirihiroka/shrimply/releases>`__, or build from source
(see :doc:`development`).

Terminal command
----------------

To add ``shrimply.exe`` to your user ``PATH``, open
:menuselection:`Preferences --> External` and select :guilabel:`Install` next
to :guilabel:`CLI`. See :doc:`integrations/cli` for details.
