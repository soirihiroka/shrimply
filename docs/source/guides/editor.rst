Editor
======

The application menu can show or hide the inspector and timeline.

The Info tab shows the selected clip's timing, size, and file details.

Timeline
--------

If an import hits existing clips, you can overwrite them, cancel the import,
or put it on a new track.

Right-click a clip to copy, cut, paste, group, or ungroup it. Depending on the
clip, you can also paste modifiers, fold a sequence, save a frame, export its
audio, transcribe it, remove silence, or generate speech.

Comment tracks
~~~~~~~~~~~~~~

Projects start without a comment track. Add one with **Add Comment Track** in
the timeline's empty-track menu, or **New Track → Comment Track** in the GTK
application menu. Use the track's **+** button and choose **Comment** to add a
comment at the playhead, or double-click an empty part of the comment track.

Drag a comment to move it. Drag either edge to change its range. Select it to
edit the text, and pick Red, Orange, Yellow, Green, Blue, or Purple in the
inspector. Comments select, snap, split, and undo like other clips.

Comments are notes. They stay out of the preview, the subtitle export, and
the rendered duration.
